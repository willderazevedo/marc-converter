## Description

A lightweight utility to parse and convert validated TXT files into standard MARC21 (`.mrc`) bibliographic records.

---

## 📌 About

**TXT to MARC21 Converter** is a tool designed to streamline the process of transforming structured text files (`.txt`) into standard binary MARC21 (`.mrc`) files, making it easy to import data into library management systems.

## 🚀 Features

- **Input Validation:** Verifies that `.txt` files follow required formatting before conversion.
- **MARC21 Standard Output:** Generates compliant `.mrc` files compatible with software like Koha, Pergamum, and Evergreen.
- **Fast & Lightweight:** Handles conversions efficiently without heavy dependencies.

## 📦 Download & Installation

1. Go to the **[Releases](https://github.com/willderazevedo/marc-converter/releases)** section of this repository.
2. Download the latest installer file.
3. Run the installer and follow the setup wizard.
4. Launch the application, then select your target `.txt` folder to generate the `.mrc` output, or simply copy and paste text directly into the app to convert a single file.
